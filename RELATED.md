# Related work

*The projects that already publish, track, or analyse the public record of U.S. officeholders, described on their own terms; what Oath is against that field; and what the field teaches the build.*

A paper carries a related-work section so a reader can see what the authors stood on and what they claim to add. This is Oath's. It exists for the same reason the humility clause in [CLAUDE.md](CLAUDE.md) exists: when another project already does something well, the honest move is to cite it and link to it, not to rebuild it or to talk past it. Being prepared to not be the best is rare, and it is the maintainer's standing instruction.

If you got here from a friend and none of this looks like your world: there are many websites that let you look up what a member of Congress owns, trades, votes on, or is paid by. This file lists the ones this project knows about, says what each is in its own words, and then says what this project is for that they are not. Nothing here is a judgement about any of them. Most are older, larger, and better resourced than this repository, and this repository links to them on purpose.

**The frame, applied to neighbours.** A project appears in this file because it works with the same public record. Presence in this file is not a claim about a project's quality, and absence is not either. If a project's maintainers read their entry and find it wrong, the correction path is a pull request, and the corrected entry supersedes the old one in the same way a Finding does.

**Contents.** 1. How to read this file · 2. The neighbourhood · 3. Design choices across the field · 4. Oath, against the field · 5. What the field teaches the build · 6. Limits of this survey · 7. Sources

## 1. How to read this file

Every entry in §2 was produced the same way, on the date given in its citations.

- **On the project's own terms.** The description paraphrases the project's own About, methodology, data, or licence page. Where a sentence is quoted, it is short and attributed. No entry rates a project. No entry compares a project to Oath; §4 does that, about Oath.
- **Cited, dated, re-read by a skeptic.** A first reader wrote each entry from the pages listed under it. A second reader, briefed to refute rather than to confirm, re-fetched every cited page and tried to knock each claim down. Claims that survived are here. Claims that did not were corrected or removed. Claims neither reader could check are marked *not verified* in the entry, not silently kept. The convergence rule from the sibling *errata* project applies: a claim about a neighbour that would flatter Oath by comparison was checked hardest, because that is the direction this project is blind in.
- **Status is a reading of the page, not a prediction.** *Active* means the site showed content dated within the twelve months before retrieval. *Merged* or *closed* means a page on the site says so. *Not verified* means the readers could not tell.
- **Properties are design choices, not scores.** §3 tabulates what each project does and does not do along axes Oath cares about. A *no* in that table is a choice the project made for its readers. Several of those choices buy a utility Oath has given up on purpose, and §4 says which.
- **Retrieved once.** Everything here was true of the pages on the retrieval date. Sites change. The retrieval date is on every citation so a later reader can weigh it.

## 2. The neighbourhood

Grouped by what a project is for. Within each group, the order is the order a reader building Oath would meet them. Every entry paraphrases the project's own pages as read on 2026-09-21; the full verified record for each, with every URL, every claim the skeptic could not confirm, and every claim the skeptic corrected, is in [docs/related-work/](docs/related-work/). ### 2.1 The primary publishers and the rule-issuing bodies

These are not neighbours. They are the ground every project in this file, including this one, stands on. They are read here because their published shape (identifiers, formats, terms) decides what any register can do. [SOURCES.md](SOURCES.md) carries them as adapters; this section carries what the survey found.

**Federal Election Commission open data.** <https://www.fec.gov/data/> and <https://api.open.fec.gov/developers/>. The FEC describes a RESTful API over its filings, updated nightly, in which "information is tied to the underlying forms by file ID and image ID", plus bulk files by two-year cycle from 1979 and form images back to 1972. Identifiers: candidate ID, committee ID, file ID, image ID. Code at `fecgov/openFEC` under a CC0 dedication. Terms: 52 U.S.C. § 30111(a)(4) forbids selling or using individual contributors' names and addresses for solicitation or commercial purposes. API key through api.data.gov; 1,000 calls an hour by default. Active.

**Congress.gov API.** <https://api.congress.gov>. The Library of Congress shares the API so the public can "view, retrieve, and re-use machine-readable data" from its collections: bills, amendments, members, committees, nominations, the Congressional Record, and House roll-call votes from the 115th Congress (marked beta). The member key is `bioguideId`, which the documentation says originates in the Biographical Directory. Key through api.data.gov; 5,000 requests an hour. No licence statement was found on any page read. Active.

**Biographical Directory of the United States Congress.** <https://bioguide.congress.gov>. Since 1859 "the primary source for biographical information on Members" of Congress, and the registry of the bioguide identifier every other project in this file uses. A per-member JSON record exists at `/search/bio/{ID}.json` but is undocumented; the site returned 403 to non-browser clients. Maintaining office, licence, and update cadence: not verified.

**House Committee on Ethics, with the Clerk's Financial Disclosure portal.** <https://ethics.house.gov/> and <https://disclosures-clerk.house.gov/FinancialDisclosure>. The Committee issues the rules; the Clerk publishes the filings. The Periodic Transaction Report form and the Committee's January 2023 memorandum state the rule Oath's first Signal will cite: a PTR is due the earlier of 30 days from notification or 45 days from the transaction, with no extensions; a report filed more than 30 days after that is subject to a $200 fee and, without the fee, is "not properly filed." The form covers transactions over $1,000 in "stocks, bonds, commodities, futures, or other securities (e.g., cryptocurrencies)." The Clerk's bulk ZIP per year carries a text and XML index (the 2025 file: 2,935 filing rows across twelve filing-type codes, whose meanings are not defined on the pages read) and one PDF per filing, keyed by an eight-digit DocID. There is no person identifier in the index; filers are keyed by name and state-district. Active.

**Senate Select Committee on Ethics, with the eFD system.** <https://www.ethics.senate.gov/> and <https://efdsearch.senate.gov>. The Senate states the same PTR rule with a written-notification prong, a May 15 annual deadline, and the $200 rule for any report more than 30 days late. Public search covers reports filed since 2012 and sits behind an agreement that the reports may not be used for commercial purposes (news media excepted), for credit rating, or to solicit money, citing 5 U.S.C. app. § 105(c). No bulk download was observed. The eFD report-identifier scheme was not observed because the readers did not pass the agreement gate. The 2025 annual report counts 4,485 public disclosure reports received in the year. Active.

**Office of Congressional Conduct.** <https://conduct.house.gov/>. The House's independent review body, renamed from the Office of Congressional Ethics by H.Res. 5 on January 3, 2025; the old domain redirects. It publishes referrals with exhibits, an investigations table, quarterly statistics (as images and PDFs), and its rules. Its own frame is the one any tracker should carry when it cites a referral: a referral means the Board found substantial reason to believe a violation occurred, and "a referral is not a finding of a violation"; only the Committee on Ethics can find one. Active.

### 2.2 Identity and reference data

The question underneath every project in this file is *which person is this row about*. These are the projects that answer it.

**The unitedstates project.** <https://github.com/unitedstates>. Volunteer-maintained, CC0 data on members of Congress from 1789 in YAML, JSON, and CSV, with committees, memberships, and social accounts, plus public-domain scrapers for bills and votes. Its README says of the bioguide field: "This is the best field to use as a primary key." The crosswalk on each current member carries, at retrieval: govtrack and bioguide (539 of 539), wikipedia and wikidata (538), ballotpedia (525), opensecrets (523), votesmart (519), and fec as a *list*, because a person can hold several FEC candidate IDs. The wikidata key is present on nearly every member but undocumented in the README. Last commit 2026-09-03. Active.

**Wikidata.** <https://www.wikidata.org>. A CC0 knowledge base whose properties link a politician's item to the bioguide ID (P1157), the FEC ID (P1839, modelling both candidate and committee IDs), the OpenSecrets ID (P2686), GovTrack (P12644), Vote Smart (P3344), and Ballotpedia (P2390), each with format and uniqueness constraints and a formatter URL to the source registry. SPARQL, an API, and full dumps are public. Community-edited. Active.

**Open States, now Plural Open.** <https://open.pluralpolicy.com>. Founded at the Sunlight Foundation in 2009, run independently from 2016, adopted by Plural in 2021; Plural's acquisition by SAI360 was announced December 1, 2025 and the announcement does not mention Open States. Aggregates bills, votes, and people for the fifty states, D.C., and Puerto Rico, with "official sources, linked at the bottom of relevant pages." The people data is CC0 and each person carries an `other_identifiers` list of scheme, identifier, and validity dates (the schema gives `votesmart` as its example and enumerates no closed list). Scrapers are GPL-3.0. API v3 with a key; rate limits not stated. Active (repositories pushed 2026-09-21).

**Ballotpedia.** <https://ballotpedia.org>. "The digital encyclopedia of American politics", 731,312 articles by professional staff, covering federal, state, and local officials, candidates, and measures, with a stated aim of covering every election in the country. Text under the GNU Free Documentation License; paid datasets and a geographic API from $500 a year under confidentiality terms. Its public person key is the article title, which is what the crosswalks store. Funded by donations, premium research, data sales, and advertising, per its About page. Active.

**Vote Smart.** <https://votesmart.org>. A nonprofit founded, by its own account, more than thirty years ago to provide "free, factual, unbiased information on candidates and elected officials": biographies, key votes, issue positions, republished interest-group ratings, and an XML/JSON API whose documentation is dated 2014 and whose terms restrict individual use to members and charge organisations. The site meters free page views. Its numeric candidate ID is carried by the crosswalks. Active (a key vote dated 2026-09-15 was observed).

**Voteview.** <https://voteview.com>. UCLA's roll-call database for every Congress since 1789, with DW-NOMINATE ideal-point scores per member per Congress, party-unity and presidential-support scores, downloads, and a weekly database dump. Its member file is the ICPSR-to-bioguide crosswalk. Primary vote feeds are not named on the pages read; no data licence is stated; a citation is requested. Active.

**LegiStorm.** <https://www.legistorm.com>. "Congress Revealed": a commercial platform, founded 2006, that posts images of members' and senior staff's personal financial disclosures with personal identifiers redacted, salaries, and staff directories on its free site, with privately funded travel from 2000, foreign gifts from the Federal Register, lobbying, and state coverage in paid tiers. No computed per-filing condition was observed. Its disclosure FAQ states that financial disclosure statements are not intended as net-worth statements. Proprietary; an API is listed under custom solutions. Active.

### 2.3 Money-in-politics aggregators

**OpenSecrets.** <https://www.opensecrets.org/>. A 501(c)(3) formed in 2021 when the Center for Responsive Politics and the National Institute on Money in Politics joined; its FAQ says nearly all its data originates with an official government source, to which it adds industry coding, employer standardisation, and household attribution. Its presence criterion is stated: once a candidate files with the FEC or a state agency, they are eligible to appear. Personal-finance profiles show annual-report data through 2018 on the section landing page and a Periodic Transaction Report database that "only displays reports for Members of the House of Representatives", back to 2012; the transactions footnote cites the Ethics in Government Act as amended by the STOCK Act and the 30/45-day rule. Per-person derived: an estimated net worth with a rank within the chamber, and top-ten lists (richest, poorest, biggest increase). Identifiers: the CID (`N` plus eight digits) and a newer numeric `mpid`. Bulk CSV under CC BY-NC-SA 3.0 US after account approval; "As of April 15, 2025, our API offerings have been discontinued." Active.

**FollowTheMoney.** <https://www.followthemoney.org/>. The state-level surface of the merged organisation: the home page states that NIMP and CRP "joined forces to become OpenSecrets", that state campaign-finance data is shown through the 2024 election, and that federal data moved to opensecrets.org. Contributions to state offices from 2000, lobbying from 2006. Entity pages keyed by a numeric `eid`; whether it maps to a CID or to state filer IDs: not verified. CC BY-NC-SA 3.0 US; free accounts capped at 1,000 records a year. Merged.

**MapLight.** <https://maplight.org/>. "MapLight creates technology to improve democracy": a 501(c)(3) founded 2005 whose current products are campaign-finance, lobbying, and ethics e-filing systems for state and local governments (California's Secretary of State, Maine, Denver, Minneapolis named), and whose earlier money-and-votes research is offered as a Bill Positions dataset, 2007 to 2021, "no longer being updated", for a licensing fee. The classic money-and-votes site was unreachable. Status unknown: no content dated within the last twelve months was found.

**Sunlight Foundation.** <https://sunlightfoundation.com/>. "As of September 2020 the Sunlight Foundation is no longer active"; the site is a static archive, and its intellectual property and records went to the Internet Archive and Harvard's Berkman Klein Center. Its 2016 note records where its tools went: the Congress API to ProPublica, Open States to an alumni group, Foreign Influence Explorer and Party Time to CRP. Closed.

**Transparency USA.** <https://www.transparencyusa.org/>. A Texas 501(c)(3) with state campaign-finance data for 25 states and Texas lobbying: "clear, accurate, easy-to-understand information about the money in state politics." Its FAQ states a rule the survey did not find elsewhere: it cannot change a transaction unless it has first been changed in the official report filed or amended with the state agency. Top-ten donor lists per state. Data sales by CSV, JSON, or API on request. No licence stated. Status unknown: no dated content within twelve months was captured.

**ProPublica FEC Itemizer and Campaign Finance API.** <https://projects.propublica.org/itemizer/>. A newsroom tool for browsing FEC electronic filings, ingested every fifteen minutes, with an API (originally The New York Times's, 2008) under CC BY-NC-ND 3.0 and 5,000 requests a day. The Data Store terms state "we do not guarantee the accuracy or completeness of the data." Active.

### 2.4 Legislative trackers

**GovTrack.us.** <https://www.govtrack.us>. A project of Civic Impulse, LLC, launched 2004, tracking bills, votes, members, and since 2025 the White House, with a posted charter committing it to report fairly and take no side. Data comes from the unitedstates repositories it co-maintains, GovInfo bulk data, and House and Senate XML; its own API and bulk data ended in 2017 because, as its timeline says, Congress created its own and other organisations created similar APIs. Per-person derived: annual report cards ranking every member within cohorts from #1 downward on thirteen statistics, an ideology score (principal components over cosponsorship) and a leadership score (PageRank), with no score for members who introduced fewer than ten bills. The report-cards page states that "a higher or lower number below doesn't necessarily make a legislator any better or worse, or more or less effective" and that the statistics are presented so readers can "make your own judgements." A CC0 database of 514 entries that GovTrack names its "misconduct" database, with stated inclusion criteria, sourced from the Senate Historical Office, the House Committee's historical summary of conduct cases, a Washington Post indictment list, a Wikipedia convictions list, and news reports; its page states that many entries are politically motivated, that some allegations were never proven, and that readers must judge for themselves. Terms encourage copying and reuse and bar using site content to develop software (including AI training) or to redistribute cached datasets; that dataset is CC0. Funded by advertising, subscribers, and crowdfunding. Active.

**ProPublica Represent and the Congress API.** <https://projects.propublica.org/represent/>. "See what your representatives in Congress say and do." A notice updated July 10, 2024 states that Represent and the Congress API are no longer available and the page is an archival snapshot. The API, which began at The New York Times in 2009, exposed a member record whose identifier block (bioguide as `id`, plus govtrack, cspan, votesmart, icpsr, crp, fec, ocd, lis) matches the unitedstates crosswalk. Use of the API was under CC BY-NC-ND 3.0; the documentation separately states the data it returned is in the public domain. Closed.

### 2.5 Watchdogs and complainants

Organisations that read the same filings Oath will read and act on them: complaints, reports, litigation, advocacy. None publishes a per-officeholder register; several state the conditions Oath's first Signals will define.

**Citizens for Responsibility and Ethics in Washington.** <https://www.citizensforethics.org/>. A "nonpartisan nonprofit government watchdog organization" working through lawsuits, FOIA, conflict-of-interest tracking, and campaign-finance complaints. Its 2021 and 2022 STOCK Act analyses describe late Periodic Transaction Reports and attribute the counts to Business Insider's reporting; its April 2023 report reads OGE Form 278e filings of 21 cabinet members and 56 White House officials against their ethics agreements for completed divestitures, gifts, and recusals. No per-officeholder table or identifier. Form 990s posted 2018 to 2024. Terms prohibit automated extraction of the site. Active.

**Campaign Legal Center.** <https://campaignlegal.org/>. "Campaign Legal Center advances democracy through law." Founded 2002 by a former FEC commissioner; a 501(c)(3). By its September 2025 count it has filed fifteen STOCK Act complaints with the Office of Congressional Ethics and the Senate committee, at least ten of them posted with PDFs on its cases page (March 2021 to September 2024), on two conditions stated per filing: a PTR filed after the deadline, and trades never reported on any PTR and found at the annual-disclosure stage. In October 2021 the OCE found substantial reason to believe a violation in one such matter and referred it. Its *Congressional Stock Trading By The Numbers* fact sheet for the 119th Congress classifies the 533 members with a filing on record (individual stock, only widely held funds, blind trust, or neither) as of November 12, 2025, alphabetically, and states that members without one are excluded, with a footnote that the counts are "reflective of the accuracy and clarity of those records." Its pages state the deadline as 45 days on some and 30 days on two others, without saying whether the 30 refers to the notification prong. Trade volumes are cited to Unusual Whales. Active.

**Foundation for Accountability and Civic Trust.** <https://www.factdc.org/>. A 501(c)(3) established 2014, "to strengthen our republic by demanding the truth", filing ethics, IRS, and FEC complaints with posted PDFs. Its October 2025 complaint against a House member is a worked instance of a condition computed from two of the same member's filings: Treasury bill purchases in 2024 that appear on the annual report filed August 2025 with no PTR in the 30-to-45-day window. Active.

**Project On Government Oversight.** <https://www.pogo.org/>. "A nonpartisan independent watchdog", founded 1981, investigating the federal government. Its June 2025 investigation reads White House-released financial disclosures for a holding in a company that contracts with the agency whose matters the official works on, cites the regulatory de minimis exemption for holdings of $1,001 to $15,000, and cites OGE's rule that a minor child's asset is treated as the employee's under 18 U.S.C. § 208; it carries the White House's response that the official has recused. Three public databases were retired: the Federal Contractor Misconduct Database in 2022, the Pentagon Revolving Door Database in 2023, and an inspector-general vacancy tracker, undated, because the government now runs the equivalent; the data is offered by email. Annual reports posted from 2001 (2002 absent) and Form 990s from 2003. Its contribution policy declines money from for-profit corporations, unions, and governments. Active.

**Public Citizen.** <https://www.citizen.org/>. "The people need advocates too." A 501(c)(4) with a 501(c)(3) foundation, founded 1971, no corporate or government money. Its June 2017 report on senators' trading 2009 to 2015, built from annual and termination reports collected from the Senate website and the Office of Public Records, maps trades to committee and subcommittee jurisdiction and reports that transaction counts fell 68 percent after the STOCK Act; it frames the Act's goal as reducing insider trading, not trading. It notes pre-2012 disclosures were not required to be preserved. Whether the dataset was published: not verified. Content under CC BY-NC-ND 3.0 US. Active.

**Common Cause.** <https://www.commoncause.org/>. "A nonpartisan, grassroots organization dedicated to upholding the core values of American democracy", founded 1970. A December 2025 article lists the ten members with the highest 2025 trade volume, sourced to Capitol Trades, with no method stated for turning disclosure ranges into dollar figures. Its Democracy Scorecard scores members on votes and cosponsorship of named bills and, it states, does not rate candidates. No per-filing condition computed. Active.

**Sludge.** <https://readsludge.com/>. A two-person, reader-funded newsroom (a project of the Participatory Politics Foundation) reporting on "how moneyed interests are shaping politics" across both parties. Its articles state, per member, conditions read from Clerk filings and from Capitol Trades: a PTR not filed within 30 days of notification or 45 of execution (August 2024); a holding in a company within the jurisdiction of a committee the member sits on, mapped from the committee's jurisdiction statement (September 2022); a household purchase days before a government announcement affecting the issuer, with the member's caucus or committee memberships noted (January and April 2026); and sector-classified household holdings summed as value ranges (September 2026, paid). Its January 2026 piece states there is no public evidence the member received nonpublic information. Filing links are present in some pieces and absent in others. No dataset or licence terms were found; the footer carries a copyright notice. Active.

### 2.6 Congressional trading trackers and products

These read the same Periodic Transaction Reports Oath's first Signal will read, for a reader who wants to trade on them, and several turn the disclosures into products. §4 says which of their utilities Oath gives up on purpose.

**Capitol Trades.** <https://www.capitoltrades.com/>. Operated by 2iQ Research of Frankfurt and free to the public, "a financial data and content aggregator" by its own disclaimer, combining automated and manual collection of Senate eFD and House Clerk filings, with the ProPublica Congress API for member details. On 2026-09-21 its default three-year window showed 37,037 trades by 211 politicians. Every trade row links to the original filing on the government's site (a House Clerk PTR PDF was the link observed) and carries a "Filed After" column, the days between trade and publication, with no threshold or late flag stated. Politician pages are keyed by the bioguide ID, which the site does not label; the second reader confirmed the scheme against the unitedstates legislators file. Ordered listings of politicians by trade count, issuers, and volume; no score or grade. Disclaimer: informational, not investment advice. No API and no licence stated. Active.

**Unusual Whales, politics section.** <https://unusualwhales.com/politics>. The politics section of a subscription market-data platform whose About page says it has zero outside funding and whose 2025 report says "We scraped all Periodic Transaction Reports (PTRs) disclosed by Congress members this year." Outputs: a trade feed with transaction and filing dates, per-politician profiles and portfolios, an FEC section, annual reports, and a paid API ($150 or $375 a month, personal use only) with a late-reports endpoint whose threshold the specification does not state and six unusual-trade reason tags (committee conflict, first person to trade, low market cap, unusual industry, unusually large trade, FEC donation conflict). Per-person derived: top Democrats and top Republicans ranked by trade count; the 2025 report reconstructs portfolios from range midpoints, estimates per-politician returns against the S&P 500, names top performers, and lists the longest disclosure delays. Its radar flags trades by 14-day alpha, loss avoidance, and committee jurisdiction, and the report states that it "does not allege insider trading or illegality." Identifiers: its own UUIDs, with FEC candidate IDs in its FEC schemas and no bioguide. The public disclosure page read did not link to the filing; the enterprise annual-disclosure schema carries the Clerk PDF URL. Terms: no redistribution. The Subversive ETFs' July 2026 prospectus supplement states the funds no longer use it as data provider. Active.

**Quiver Quantitative.** <https://www.quiverquant.com/>. "Trade Like an Insider": a retail alternative-data platform founded in 2020, with a free dashboard, a premium tier at $25 a month, and a paid API from $30 a month. Its Congress Trading page states the 45-day rule and says "We download those disclosures, parse them for stock trades"; the government sites are not named on the pages read. Per trade: filed and traded dates and an estimated excess return against the S&P 500 since the transaction. Per politician: a return chart against SPY, an estimated live portfolio from annual disclosures with a note that holdings occasionally contain parsing errors, a most-active-traders list, a highest-net-worth list, and a premium portfolio leaderboard; backtested strategies. The API returns the bioguide ID as a first-class field, offers three ways to turn a disclosed range into a volume (range start, average, range end), and has a bulk endpoint for the President's trades. Python client on PyPI under MIT (repository `Quiver-Quantitative/python-api`); the data is proprietary and personal-use only. Its disclaimers page says nothing on the site is legal or accounting advice and backtests are hypothetical. Active.

**Senate Stock Watcher, House Stock Watcher, and a 2026 successor.** <https://github.com/timothycarambat/senate-stock-watcher-data>. An open GitHub dataset of Senate PTRs as daily JSON, each filing carrying a `ptr_link` to the eFD record, described in its README as data from efdsearch.senate.gov; no licence file; last pushed March 2021. Its site domain did not resolve on 2026-09-21 and no page states the project has ended. The House counterpart's domain did not resolve and its data bucket returned 403, so nothing about it could be read. A separately named 2026 repository, `TattooedHead/house-stock-watcher-data`, publishes House PTR trades as JSON with a `filing_id` and a `source_url` to the Clerk PDF on every row, an `amount_mid` field, and a scheduled scraper; its README says the author wrote it with Claude Code after finding nothing working that did this; no licence file; last pushed 2026-09-19. Whether it descends from the original is not stated.

**Autopilot.** <https://joinautopilot.com/>. "Invest alongside politicians & real-time traders": an app, with an adviser subsidiary described as SEC-registered, that copies published portfolios into a user's linked brokerage account, including trackers named for individual members of Congress and portfolios authored by Unusual Whales and Quiver Quantitative. Its tracker page says the team read new filings each morning and called out trades it considered potential conflicts, and states more than $1.1 billion invested by more than 180,000 people and a goal of supporting a trading ban. No government source is named and no person identifiers are exposed; portfolios are ranked by return and by dollars invested. Its disclaimer discloses a referral arrangement with a brokerage as a conflict of interest. Active.

**Subversive Congressional Trading ETFs.** <https://subversiveetfs.com/>. Two actively managed funds, NANC for Democratic members and GOP (formerly KRUZ) for Republican members, that hold what members and their spouses reported on PTRs over a three-year window, weighted by size and recurrence, using range midpoints, netting purchases against sales, 100 to 200 holdings. The fact sheet says the adviser "will only buy or sell what members of Congress hold" and expresses no view. Management fee 0.72 percent; expense ratio 0.73 percent. The prospectus lists "Reporting Delay Risk" and "Ethics in Government Act Risk", the uncertainty about commercial use of PTRs, and states the 30- and 45-day prongs. Daily holdings as CSV; no person identifiers. Active.

**Finnhub.** <https://finnhub.io/docs/api/congressional-trading>. A premium endpoint of a commercial financial API returning members' trades by ticker with filing and transaction dates; no source agency named, no person identifier, no filing link. Status unknown.

The second reader named eight more products of this kind it did not read (Financial Modeling Prep, Barchart, InsiderFinance, Congresstrading.com, an open Senate disclosure dataset, and four tracker sites); they are listed in the record.

### 2.8 Analogues abroad, and structural analogues

Registers of officeholders' declared interests exist in other countries, and a few projects hold structured records of politically exposed persons worldwide. They are read here for their shape: how they key a person, how they show change, and what they say a listing means.

**TheyWorkForYou, with ParlParse.** <https://www.theyworkforyou.com/>. mySociety's parliamentary monitor for the UK's parliaments, on the premise that "information about our elected representatives should be easily understandable and accessible to everyone." It ingests the House of Commons Register of Members' Financial Interests as periodic XML snapshots (editions from 2001 to 7 September 2026) and lets a reader compare consecutive editions to see what changed, with both editions kept; the raw XML it parsed is published beside the rendered page. The member register page links to the official register's landing page on parliament.uk, not to the specific edition. Per-person derived: voting summaries on a 0 to 100 scale rendered as seven phrases, from "consistently voted for" to "consistently voted against," with absences not counted. Identifiers: its own integer person ID and the Parliament ID. Parliamentary material under the Open Parliament Licence; its own data under CC BY-SA 2.5; code under a BSD-style licence, ParlParse under AGPL-3.0. API with a free tier of ten calls a day. Active.

**abgeordnetenwatch.de.** <https://www.abgeordnetenwatch.de/>. Parlamentwatch e.V., a donation-supported association, publishes German legislators' disclosed side activities and side income from the Bundestag administration's publications, with a research desk on potential conflicts of interest. Each politician record carries the Bundestag administration's own ID and a Wikidata QID, and each side-job row keeps the exact figure and the statutory bracket side by side with the interval and the recording date. Its June 2026 overview states the thresholds and deadlines it reads against and that whether members comply with disclosure duties is hard to verify from outside (paraphrased from the German). It lists the members with the highest disclosed side income and offers a sortable table of all 630. API v2 under CC0, no key, thirty requests a minute. Active.

**Integrity Watch EU.** <https://www.integritywatch.eu/>. Transparency International EU's hub, launched 2014, "that allows everyone to monitor the integrity of the EU's decision makers": MEP declarations of interests and side income, MEP and Commission lobby meetings, and the lobby register, retrieved from the institutions' own sites and, its About page states, entirely self-reported, for whose accuracy the operator takes no responsibility. The income table carries an "Estimated annual income" column whose derivation is not stated on the page. A note on the income page says some declarations are missing from the Parliament's site. Data under ODbL 1.0. Status unknown: no dated content within twelve months was observed.

**Transparency International.** <https://www.transparency.org/>. The Berlin secretariat's work on asset and interest declarations is policy: a 2020 paper for the Open Government Partnership proposes that OGP could incubate "a future open data standard for asset declarations," and its 2013 news piece sets out principles (all three branches, filed at the start of office, updated annually, verified by an agency). No central dataset of declarations was found on transparency.org; the skeptic notes that the Russian chapter's Declarator.org holds one and is queued for the second sweep. Active.

**OpenSanctions.** <https://www.opensanctions.org/datasets/peps/>. "A financial crime data provider" (OpenSanctions Datenbanken GmbH, Berlin) whose politically-exposed-persons dataset holds about 1.95 million entities from 202 sources, including a daily-updated U.S. Members of Congress dataset read from the Congress.gov API. Its identifier design: the Wikidata QID as the entity ID where one exists, source-prefixed IDs otherwise, cluster IDs for merged profiles, and a `referents` table that forwards retired IDs for six months. Its PEP documentation states that being classified as a PEP is not an allegation but a risk category arising from the nature of senior public office, and that the project does not make decisions about individuals (paraphrased). Retention after leaving office is declared as the project's own judgment, with occupancy dates kept so a user can apply another. Data under CC BY-NC 4.0 with commercial licences; pipeline MIT; API key required, free for journalism and research. Active (updated 2026-09-21).

**EveryPolitician.** <https://everypolitician.org/>. mySociety's original dataset of 78,382 national legislators in 233 countries was placed on hold on 26 June 2019, its post citing the upkeep of scrapers against near-weekly elections worldwide; the frozen data remains downloadable. In February 2026 the domain relaunched as an OpenSanctions project built on Wikidata and official-source crawlers, now listing 702,610 politicians in 211,185 positions. The original per-person UUIDs survive as referents on OpenSanctions entities. Its PoliLoom tool uses language models to extract politician data from Wikipedia for human review before anything is written to Wikidata. CC BY-NC 4.0. Active in its second life.

**LittleSis.** <https://littlesis.org/>. The Public Accountability Initiative's "free database of who-knows-who at the heights of business and government": about 400,000 people and organisations and 1.6 million typed relationships, volunteer-edited, selected by the mission to track "people and groups with inordinate wealth, influence on public policy and access to government officials." One elected-representative record carries bioguide, GovTrack, OpenSecrets, Vote Smart, and FEC IDs and a Wikidata slot. Search results are ordered by relationship count. Its disclaimer states there is no formal peer review and offers a review form. CC BY-SA 4.0; keyless JSON API; code GPL-3.0. Active.

**OCCRP Aleph.** <https://aleph.occrp.org/>. The Organized Crime and Corruption Reporting Project's data platform, "built to help investigative journalists track people and companies," for searching leaks, registries, sanctions lists, and court archives and mapping entity connections. The open-source codebase reached end of official support on 31 December 2025, in maintenance mode, while the hosted service continues as Aleph Pro, free for nonprofit newsrooms. What the public instance holds on U.S. officeholders could not be verified from outside; the collections API returned 401 without an account. Active.

## 4. Oath, against the field

Five short answers, in the order a reader building or funding something like this would ask them. Each is stated against the field in §2, and each is a commitment the Charter already makes; this section only says what those commitments amount to when the neighbours are in view.

**Identity.** Oath is a register. Not a watchdog, which complains and litigates; not a scoreboard, which ranks; not a tracker, which alerts. A register is a structured, sourced, sealed list of what the public record contains about a defined population, kept so that a stranger can check any row against its source without trusting the keeper. The nearest things to it in §2 are not the trading trackers or the watchdogs but the reference infrastructure: an identifier crosswalk, a legislator file, a corrections record. Oath is that kind of object, pointed at the sworn commitment and the disclosures the law hangs on it.

**Mission.** To reconcile what an officeholder swore with what the record shows, in the law's own terms, per officeholder, with the reader drawing the line. The standard is the oath (U.S. Const. Art. VI cl. 3; 5 U.S.C. § 3331) and the statutes and rules that make parts of it measurable (the Ethics in Government Act, the STOCK Act, 5 CFR § 2635, the Emoluments Clauses, the chambers' own rules). Every Signal names one of those. No Signal names a principle, a party, or an opinion.

**Purpose.** To make the checking possible for a reader without a subscription and without a law degree, in a form that never asks them to believe this project. The walk in [PIPELINE.md](PIPELINE.md) is the purpose stated as a story: from a Finding to the filing at the source in one click, and from the filing to a proof the register did not invent or later edit the number, on the reader's own machine.

**Value.** Four properties the field, read together, does not offer in one place, and a fifth that none of the surfaces read records as a result. Whether any neighbour seals or anchors a build, or witnesses its captures, was not a question the survey asked; those two are stated below as Oath's commitments, not as a comparison.

- *Standard-visible.* The statute, section, or rule behind every flag is stated beside the flag, and a Signal that cannot cite one does not ship (Rubric gate 2).
- *Machine-checkable.* Every Finding regenerates byte-identically from named filing rows, and every filing row carries its source URL and retrieval time (Invariants §3, §4).
- *Sealed and anchored.* Every build carries a digest a stranger can recompute, witnessed on a ledger the authors cannot rewrite (Methodology §6). The verifier is standard-library Python and short enough to read.
- *Evidence captured, hashed, timestamped, and witnessed by a party that is not this project.* Every cited filing is, per EVIDENCE.md, so the citation survives link rot, silent edits, and takedowns. LegiStorm hosts its own images of filings and TheyWorkForYou publishes the raw register XML it parsed; whether either hashes, timestamps, or witnesses its captures was not asked.
- *Silent by default.* The register says nothing about an officeholder for whom no defined condition is present, and records that silence as the result (Vow III). Of the surfaces in §2, none the survey read records the absence of a condition as a result in the register itself; Campaign Legal Center's census comes nearest, with a per-member *neither* category. Oath's reader comes for a check, and a quiet page is the check passing.

**Utility.** What a reader can do with Oath that §2 does not show them doing elsewhere: look up one officeholder and see, on one page, every filing the source publishes for them, with its source, every defined condition the record raises with its standard, and every defined condition it does not; walk from any claim to the primary filing without leaving the government's site; and cite a specific build by digest so the citation cannot drift. Two further things a reader can do with Oath are things the open-code neighbours already allow: rebuild the whole thing on their own machine (TheyWorkForYou, Open States, OpenSanctions, LittleSis, and the unitedstates scrapers publish their code), and fork the shape for another jurisdiction (TheyWorkForYou has been forked to Australia). Oath adds to those only the SPEC.md checks a fork can be held to.

**What Oath gives up, on purpose.** Utility the field offers and this register declines, named so a reader who needs it goes to the right place instead of waiting for Oath to provide it.

- *Ranking and leaderboards.* Who traded most, who filed latest, who holds the most. Useful to a trader and to a reporter; forbidden here (Invariants §13), because a rank is a curation of persons and the register does not curate persons.
- *Alerts and feeds.* A new trade, a new filing, pushed to a reader. Oath rebuilds on a cadence and shows the diff in its release notes; it does not push.
- *Copy-trading.* Mirroring a disclosed trade. Out of scope by construction; the register is not a market-data product and the licence does not make it one.
- *Scores.* An ethics score, a conflict index, a report card. A Signal is pass or fail against a cited standard and never aggregates into a number about a person.
- *Verdicts.* Whether a condition is a violation. Reserved to the ethics committees, the Office of Government Ethics, state commissions, inspectors general, prosecutors, and courts (Methodology §11).
- *Party.* No party label on any officeholder surface, so a structurally identical fact produces a structurally identical page for an ally and an opponent (Council seat A).

## 5. What the field teaches the build

Each item below is a fact from §2 turned toward a step on the course in [NEXT.md](NEXT.md) or a rule in the doctrine. Where the field does something Oath's laws forbid, the item says what the field does and what Oath's rule is, and stops. The projects are named because the facts are theirs; none of this is a judgement of their choices, which serve their readers.

**5.1 Identifiers (NEXT.md Phase 2, D.3).** The field has a working convention and Oath should adopt it rather than invent one. The bioguide ID is the member key in the Congress.gov API, the primary key the unitedstates README recommends, the `id` the retired ProPublica API used, and a property on Wikidata, Voteview, and LittleSis records. The crosswalk to everything else (FEC, OpenSecrets, GovTrack, Vote Smart, Ballotpedia, ICPSR, Wikidata) already exists in CC0 form in `unitedstates/congress-legislators`, which Oath can vendor and seal; its FEC field is a list, because a person accumulates candidate IDs, and Oath's schema must allow that. The shape for storing a crosswalk is Open States's `other_identifiers`: scheme, identifier, start date, end date. The design for changing keys later is OpenSanctions's: one canonical ID, source-prefixed IDs otherwise, and a forwarding table of retired IDs kept for a stated grace period, which is how EveryPolitician's original UUIDs survived its move to Wikidata. Two limits to record now: the House Clerk's filing index carries no person identifier at all, so the join from a filing to an officeholder is by name, state-district, and year, and that join is a place errors will enter; and the Senate eFD's report-identifier scheme was not observed, because it sits behind an agreement gate, so the first adapter session that passes the gate records the scheme before anything else. In the trading cluster the convention holds unevenly: Capitol Trades keys politician pages by the bioguide ID without labelling it, Quiver Quantitative returns the bioguide ID as a first-class API field, Unusual Whales uses its own UUIDs and carries FEC candidate IDs only in its FEC schemas, and the two open stock-watcher datasets key by name and district.

**5.2 Sources (NEXT.md Phase 3, I.1; SOURCES.md).** The House Clerk publishes one ZIP per year with a text and XML index and one PDF per filing, keyed by DocID; the 2025 index carries twelve filing-type codes whose meanings no page read defines, so the adapter stores them and interprets none until a Clerk document is cited. The Senate's public search requires agreeing that reports will not be used for commercial purposes, credit rating, or solicitation (5 U.S.C. app. § 105(c)); that agreement binds Oath's adapter, belongs quoted in [LIMITATIONS.md](LIMITATIONS.md), and belongs in the consumer contract in [ECOSYSTEM.md §3](ECOSYSTEM.md), because a downstream user who strips the frame may also fall outside the statute's permitted uses. The FEC ties every API record to a file ID and image ID, which is the citation anchor an adapter stores on each campaign-finance row. GovInfo's bulk bill-status data, named as the upstream by GovTrack, the unitedstates scrapers, and Congress.gov itself, had no row in SOURCES.md; F.8 adds one. The Office of Congressional Ethics is now the Office of Congressional Conduct at conduct.house.gov, with the old domain redirecting; F.9 carries the new name with the old as an alias. Three neighbours show the per-row link to the primary filing that Invariant §4 requires of every Oath row: Capitol Trades links every trade to the filing, Senate Stock Watcher carries a `ptr_link` per filing, and house-stock-watcher-data carries `source_url` and `filing_id` per row. Unusual Whales exposes the Clerk PDF URL only at its enterprise tier, and Quiver's rows were not observed to link. Both commercial platforms' terms forbid redistribution, so Oath cites them and reads the Clerk and the eFD itself. Four rows in SOURCES.md and the README's list of aggregators described things that had changed, and were rewritten in the commit before this file: Follow the Money is the state-data surface of OpenSecrets since the 2021 merger; MapLight's money-and-votes data ended in 2021 and its current products are the filing systems some state agencies use to collect disclosures, which makes it relevant as the vendor behind certain state primaries rather than as an aggregator; ProPublica's Represent and Congress API closed in July 2024; and OpenSecrets discontinued its API on April 15, 2025, so an adapter would read its bulk CSV under an educational-use account and a CC BY-NC-SA licence that does not allow Oath to relicense anything derived from it.

**5.3 The first Signal (NEXT.md Phase 2, S.1).** The late-PTR condition is the most-trodden ground in the field. The House PTR form and the Committee's 2023 memorandum, and the Senate's Financial Disclosure page, state it as the rule-issuers: due the earlier of 30 days from notification or 45 days from the transaction. Campaign Legal Center has filed complaints on it since 2021, the OCE has referred a matter on it, FACT files on it, Sludge reports it per member, CREW analyses it, and Common Cause cites CLC on it. Three consequences. The definition cites the chambers' own text, not a summary, because a summary can state one prong of a two-prong rule without saying which: CLC states 45 days on some pages and 30 on two others, and the pages do not say whether the 30 is the notification prong. The notification date is a field on the PTR form, so the 30-day prong is computable from the filing itself, not only the 45-day prong. And the House states a second, distinct, citable condition that no watchdog computes: a PTR filed more than 30 days after its due date without the fee "is not properly filed", which is a different fact from *late* and should be its own Signal or its own criterion. The trading trackers measure lateness without defining it in public: Capitol Trades prints the days between trade and publication on every row and states no threshold; Unusual Whales's API has a late-reports endpoint whose threshold its specification does not state, while its 2025 report counts late transactions against 45 days; the ETF prospectus states both prongs as a risk to the funds. A versioned public definition is what Oath's first Signal adds to that field.

**5.4 The second Signal and the ones after (NEXT.md Phase 4, S.5).** NEXT.md proposes for S.5 a PTR-reported asset absent from the most recent annual disclosure. The field's worked instances run the other way, a transaction on the annual disclosure with no PTR in the window, and that direction has two of them: CLC's undisclosed-trades complaints, and FACT's October 2025 complaint built from one member's annual report and the absence of PTRs for the purchases on it. S.5 should take the field-tested direction first; the direction NEXT.md wrote can follow as its own Signal. Two further conditions appear in the field and each carries a design warning. A holding in a company within the jurisdiction of a committee the member sits on (Public Citizen, 2017; Sludge, 2022) is computable, but the mapping from a committee's jurisdiction statement to a list of companies is an editorial act, and the Rubric would require it to be a versioned, Council-reviewed artefact of its own. A trade shortly before a government action affecting the issuer (Sludge, 2026) is the condition the field states most carefully and the one Oath should not define first, because timing alone cannot be described without the reader inferring intent; Sludge's own sentence, that there is no public evidence the member received nonpublic information, is the minimum any such row would need, and the `not_saying` field is where a Signal author says so. For the executive-branch population in [SUBJECTS.md §2.2](SUBJECTS.md), the field supplies two conditions read against a cited standard: from OGE Form 278e, a divestiture promised in an ethics agreement and not shown completed (CREW, 2023); and from White House-released financial disclosures, a holding in a contractor of the official's own agency, with the de minimis exemption and the minor-child attribution rule cited to 18 U.S.C. § 208 and OGE (POGO, 2025). Both map to [STANDARDS.md](STANDARDS.md) S.3 and R.1 Subpart D.

**5.5 Ranges, derivations, and what the register will not compute (Invariants §13).** Disclosures report value ranges, and the field turns ranges into numbers in several ways: OpenSecrets ranks members by the midpoint of an estimated net-worth range; Common Cause's December 2025 list republishes Capitol Trades's dollar volumes without restating the method; Integrity Watch EU shows an estimated annual income whose derivation is not on the page; Quiver Quantitative's API offers three ways to turn a disclosed range into a volume; Unusual Whales reconstructs portfolios from range midpoints to estimate returns; the Subversive ETFs' prospectus uses midpoints and nets purchases against sales. Oath's rows carry the range the filing reports and no derived figure. Where a derived number is ever unavoidable, it is labelled derived, versioned, and its method is on the page beside it. The field also carries per-person derived scores of many kinds, each with a stated purpose for its readers: GovTrack's report cards and ideology score, Voteview's NOMINATE, TheyWorkForYou's voting phrases, Vote Smart's republished interest-group ratings. A table sorted by a disclosed figure, such as abgeordnetenwatch's members by disclosed side income, is a different thing, and Oath's own gate permits sorting by fields the register did not compute. Oath's rule is that no number about a person, ranked or scored, appears on any surface; the Signals are pass or fail against a cited standard and never aggregate. A frame beside a rank is the field's common pattern (GovTrack states that a higher number does not make a legislator better or worse); Oath's design is that there is no rank for the frame to sit beside.

**5.6 The frame, in the field's words (Vow II, Invariant §7).** Oath's frame sentence has company. OpenSanctions states that being classified as a politically exposed person is not an allegation but a risk category arising from the office. The Office of Congressional Conduct states that "a referral is not a finding of a violation." GovTrack states that a higher or lower number on its report cards does not make a legislator better or worse and that readers make their own judgements, and its investigations database states that some allegations were never proven and that readers must judge for themselves. Unusual Whales's 2025 report states that its radar flags outliers for public review and "does not allege insider trading or illegality." The Subversive ETFs' fact sheet states the adviser "will only buy or sell what members of Congress hold" and expresses no view. Campaign Legal Center's fact sheet states that its counts are "reflective of the accuracy and clarity of those records." abgeordnetenwatch states that compliance with disclosure duties is hard to verify from outside. Transparency USA states it changes a transaction only when the official report has been amended. TheyWorkForYou keeps both editions of a register and shows the difference. These are the nearest analogues to Vows II, IV, and V, and the frame text on Oath's pages can cite them as such.

**5.7 Limits the field states that Oath inherits (LIMITATIONS.md).** The register can show what was disclosed, not whether disclosure was complete; that sentence, in CLC's and abgeordnetenwatch's words above, belongs in LIMITATIONS.md §11 beside *silence is a legitimate result*. Public Citizen notes that Senate disclosures before 2012 were not required to be preserved, which bounds any retrospective coverage under [SUBJECTS.md §6](SUBJECTS.md). CREW's 2020 report recommends that filings be rejected if scanned rather than electronic, which is a statement about how much of the corpus is OCR-bounded. The Senate committee received 4,485 disclosure reports in 2025, a denominator worth printing when Oath first reports firings per Signal per build.

**5.8 What happens to endpoints over a decade (EVIDENCE.md; the cite-the-build rule).** Stated as what the pages say, because it decides Oath's architecture and not because any of it was avoidable: the Sunlight Foundation's APIs ended in 2016 and the organisation in 2020; GovTrack ended its API in 2017 when Congress and others had built their own; ProPublica's Congress API closed in 2024; OpenSecrets discontinued its API in 2025; two POGO databases were retired in 2022 and 2023 and a third, undated, because the government now runs the equivalent; the Aleph open-source codebase reached end of support at the close of 2025; EveryPolitician paused in 2019 and returned under a new owner in 2026; the Senate and House Stock Watcher sites did not resolve in September 2026, their data last pushed in 2021, and a stranger rebuilt the House dataset from scratch in 2026 after finding nothing working. Oath cites builds, not URLs, captures the bytes of every filing with an outside witness, and vendors CC0 reference data rather than calling an aggregator's endpoint, because this is the ordinary life of an endpoint.

**5.9 Scope and the solo operator (METHODOLOGY.md §9).** mySociety's stated reason for pausing EveryPolitician was the upkeep of scrapers against elections held somewhere in the world nearly every week. Oath's subject scope is narrow for the same reason, and SUBJECTS.md says so. A register a single maintainer can rebuild on one machine covers a few hundred officeholders and a handful of sources, and grows only when each new source has an adapter that runs on a schedule without a person watching.

**5.10 Cite, do not rebuild (the humility clause).** OpenSecrets's industry coding and household attribution, Ballotpedia's rosters, LegiStorm's disclosure and travel images, Capitol Trades's trade archive, Wikidata's crosswalk, and TheyWorkForYou's edition diffing are work Oath cites and links to beside the primary record. The register's contribution is the five properties in §4 applied to one population against cited standards; everything else in this file is a shoulder, and the reader is sent to it.

**5.11 A standard that does not exist yet (SPEC.md).** Transparency International's 2020 paper proposes that an open data standard for asset declarations be incubated, and none was found in the field. Oath's schemas therefore conform to no external standard, and SPEC.md should say so plainly. The one interoperable model in the field for entities and positions is the FollowTheMoney entity model that OpenSanctions and Aleph share (a data model, not the FollowTheMoney.org site); an export of Oath's officeholder and office rows in that model would be readable by both, and is a Phase 6 item, not before.

## 6. Limits of this survey

Stated in the order a careful reader would raise them.

**It describes pages, not projects.** Each entry is what a project's own pages said on the retrieval date. A project can be more, or less, than its About page. Where the readers could not reach a page, the entry says so rather than guessing.

**It was read by two AI readers and one human.** The first reader wrote, the second tried to refute, the maintainer reviewed. Both readers share priors and both can be wrong the same way. The errata record is explicit that a second AI seat corrects one bias and installs its own; the remedy is the primary page, which is why every claim carries its URL.

**One requested entry is not here yet.** A named investigator's media platform was read and drafted for §2 but had no first-reader record and no skeptic pass, and the Council read that as a weaker standard for the one named individual in the file. It is held until it gets the same treatment as every other entry.

**One cluster has had one reading only.** The journalism precedents (§2.7) were read once; their second reading did not complete within the session's budget. Their entries are held, and the first reading is kept off the repository, until the second is done.

**It is not exhaustive.** A third reader was briefed to find what the first two missed, and what it found was swept and re-checked the same way. The projects it did not find are not in this file. Absence from §2 means the readers did not find a project, not that it does not exist.

**It will go stale.** Every entry is dated. A project listed as active may have closed; a project listed as closed may have returned. The retrieval date is the reader's tool for weighing that.

**The properties table is coarse.** A *yes* or *no* on an axis hides the design behind it. The table exists so a reader can see the field's shape at a glance; the entries in §2 are where the shape gets its detail.

**It says what Oath is for, from inside Oath.** §4 is this project describing itself. It is held to the same rules as everything else here (no verdicts, cited to the doctrine it claims), and it is still an interested party's account. The check is §2: if the neighbours do what §4 says only Oath does, §4 is wrong, and the correction path is a pull request.
