# Code of Conduct

The Charter is Oath's rule for how the register treats the officeholders it describes. This file is Oath's rule for how the register's contributors treat each other, and each other's work.

## The rules

**Describe, do not condemn.** The Charter's Vow I applies to how we treat officeholders. Its spirit applies to how we treat each other. If you disagree with a contribution, name what you disagree with and why; do not name what the contributor is. *Their commit misreads the Standard on point five* is a reviewable claim. *They are careless* is not.

**Bring receipts.** If you assert a defect, cite the row, the line, or the transcript. If you assert a fact about a Standard, cite the section. If you assert a fact about the world, cite the primary source. This is the discipline the register uses on its subjects; it is also how we treat each other's arguments.

**Read before you refute.** Do not respond to a summary of a contribution. Read the diff. If a Council session has already answered your concern, the answer is in the PR; find it before restating the concern.

**The Council is not a court.** Council seats are perspectives, not verdicts. A Council finding is a report you may act on or override in writing. Do not use the Council to prosecute a contributor.

**Political disagreement is not misconduct.** This project touches politically charged subjects by design. A contributor who disagrees with a Signal's construction, a Standard's interpretation, or a coverage decision is doing the project's work; the disagreement route is a PR or a review comment, not an interpersonal complaint. A contributor who reads structural disagreement as bad faith is the one departing from this Code.

**Personal attack is misconduct.** Naming a contributor's identity, employer, background, or motives in place of engaging with their contribution is out of scope for this repository. A single instance is a warning; a pattern is grounds for the Maintainer to close a contributor's open PRs and decline future ones. Per BYLAWS.md §1.2, contributor status is per-PR; nobody has a persistent seat that this could take from them, but a contributor with a pattern of personal attack is not welcome to open more.

**Doxing and harassment.** Absolutely not. Publishing a contributor's personal information (address, workplace, family) is grounds for the strongest response the Maintainer has, up to legal referral.

**Officeholders are not fair game either.** The register describes officeholders' filed records. It does not publish their personal information (private addresses, family details, medical history) even when public elsewhere. A contribution that goes further than what the filing itself carries is not published.

## How this Code is enforced

The Maintainer holds enforcement authority. There is no committee. This is small on purpose:

- A first-time issue: the Maintainer replies on the thread, names what needs to change, and gives the contributor the opportunity to change it.
- A repeated issue: the PR is closed with the reason cited from this file.
- A pattern: future PRs from the contributor are declined. The decision is recorded in a public log at `docs/coc-actions.md` (created when the first action lands) with the PR number and the reason, in the manner of the [Council overrides](COUNCIL.md) log.

There is no separate reporting channel for Code of Conduct issues. This is a small, transparent project; disagreements happen in public in the PR that produced them, or they do not happen at all. If a situation cannot be resolved in public, the Maintainer's email is available on the contributor's own commit history and may be used.

## The spirit of the rules

Trust and genuinely good people are hard to find, and the register's job is to be checkable so that goodness does not have to be assumed. The same is true of this Code. The rules are short so a stranger can hold everyone here to them, including the Maintainer, including the AI collaborator, including anyone who arrives tomorrow with a pull request nobody expected.

The register exists to make the record about others honest. This file exists to make the record among ourselves honest. Both are the same discipline in different rooms.
